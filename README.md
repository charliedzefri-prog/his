# 📜 История Беларуси — интерактивный тест

77 вопросов в двух вкладках: первобытность, восточные славяне, Полоцкое и Туровское княжества, феодализм.

- **Вкладка 1 (45 вопросов):** ЦТ 2011–2020 — выбор ответа, вписать слово, соответствия
- **Вкладка 2 (32 вопроса):** сборник (Часть А/В) + Решу ЦТ — включая задания на последовательность событий

## Возможности
- Автопроверка с баллом и разбором (✅/❌ + правильный ответ)
- Скачивание листа результатов (вопрос → ваш ответ → верно/неверно → правильный ответ)
- Скачивание пустого бланка вопросов
- Ключ ответов (работает даже без JavaScript)

## Запуск
Просто откройте `index.html` в браузере. Файл `test_istoriya_belarusi.js` должен лежать рядом.

## Деплой
Статический сайт на [Render](https://render.com) (конфиг — `render.yaml`).
